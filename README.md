# Расчёт площадей — Android (Kotlin + OpenCV)

Порт алгоритма из `area_final_uiv3.m` на Android. Открывает PDF или картинку,
находит замкнутые фигуры, считает их площадь в см², рисует красный контур и
подписывает площадь. PDF открывается встроенным `PdfRenderer` — Ghostscript не нужен.

## Как собрать APK

1. Установи **Android Studio** (https://developer.android.com/studio).
2. `File → Open` → выбери папку `AreaCalcAndroid`.
3. Дай Android Studio скачать зависимости (OpenCV подтянется автоматически с Maven Central).
4. При первом открытии Android Studio сам создаст файл `local.properties` с путём к SDK
   и сгенерирует Gradle Wrapper. Если предложит — согласись обновить/синхронизировать.
5. Собрать APK: меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
   Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
6. Перекинь APK на телефон и установи (нужно разрешить установку из неизвестных источников).

### Сборка из командной строки (если Wrapper уже создан)
```bash
cd AreaCalcAndroid
./gradlew assembleDebug
```

## Параметры алгоритма

Меняются в `app/src/main/java/com/areacalc/app/AreaProcessor.kt`:

| Параметр      | Значение | Смысл (как в MATLAB)                          |
|---------------|----------|----------------------------------------------|
| `minAreaCm`   | 5.5      | минимальная площадь фигуры, см²              |
| `solid`       | 0.0      | порог компактности (Solidity)                |
| `maxDisk`     | 20       | максимальный размер замыкания контуров       |
| `scaleFactor` | 2        | ускорение: 1 — точнее, 2–3 — быстрее         |

## Как определяется масштаб (пиксели → см²)

| Вход | Масштаб |
|------|---------|
| PDF | автоматически из размера страницы (рендер при известном DPI) |
| Фото / картинка листа | **находится лист бумаги, выпрямляется перспектива** (`SheetDetector`), масштаб берётся из выбранного размера листа (A4/A3/A5/Letter) |
| Лист не найден | откат: весь кадр считается выбранным листом |

Размер листа для фото выбирается в выпадающем списке в приложении.
Детектор листа (`SheetDetector.kt`) убирает искажение от угла съёмки
(`warpPerspective`) и одновременно даёт точный масштаб, т.к. размер листа известен.

**Важно для фото:** лист должен быть виден целиком и контрастировать с фоном
(например, белый лист на тёмном столе). Если лист сливается с фоном — сработает
откат «весь кадр = лист», и точность упадёт.

## Что перенесено 1-в-1 из MATLAB
- порог `gray <= 210`;
- расчёт на уменьшенной копии (`scaleFactor`) с обратным увеличением маски;
- цикл по размерам «диска» `[1 3 5 … maxDisk]`;
- `close → dilate → close → fill holes → erode`;
- фильтр по площади и Solidity;
- перевод площади: `area_px / (dpi/2.54)²`.

## Ограничения
- `insertText` из MATLAB заменён на `putText` OpenCV (шрифт другой, но читаемый).
- Многостраничные PDF с большим DPI требуют памяти — при нехватке снизь `DPI`.
- `fillHoles` считает угол (0,0) фоном (стандартное допущение).
